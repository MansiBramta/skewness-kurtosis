# Skewness & Kurtosis: From Moments to Machine Learning

This repository contains the supporting materials, visualizations, and resources created for my article:

**“Skewness & Kurtosis: From Moments to Machine Learning”**

The article explores the mathematical foundations, intuition, interpretation, and practical applications of skewness and kurtosis, with a focus on how these concepts connect to statistics, exploratory data analysis, and machine learning.

## Topics Covered

* Moments
* Central moments
* Skewness
* Kurtosis
* Excess kurtosis
* Mathematical intuition behind the formulas
* Distribution shapes and interpretation
* Skewness and kurtosis in EDA
* Standardization vs. skewness
* Data transformations
* Applications in Machine Learning
